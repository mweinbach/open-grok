# Open Grok v1.0.0-open-grok.64

This release imports the August 13, 2026 upstream Grok Build snapshot while preserving Open Grok's provider isolation, Code Mode behavior, branding, and dedicated state paths.

## Agent runtime and sessions

- Adds structured turn-end reporting and hooks, including cancellation and failure coverage.
- Improves subagent lifecycle tracking, retry execution, partial-output preservation, and usage accounting.
- Strengthens prompt queue, scheduled-task, reconnect, permission-prompt, and background-task behavior.
- Adds session-search gating and eviction coverage so disabled or deleted sessions do not leave stale indexes.

## Hooks, tools, and workspace

- Expands hook event handling, command and HTTP runners, notification metadata, and stop/cancel behavior.
- Improves scheduler execution, web-search domain filtering, and tool override handling.
- Updates workspace filesystem, daemon, preview, and status behavior with additional regression coverage.

## Pager and configuration

- Adds configurable follow-up behavior and related keyboard, settings, and session documentation.
- Improves plan, queue editing, selection, subagent activity, and session notification rendering.
- Updates the default xAI model and web-search route to Grok 4.6 while retaining Open Grok's fork-only provider catalog.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout the upstream import.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
