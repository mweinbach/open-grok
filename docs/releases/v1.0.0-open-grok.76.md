# Open Grok v1.0.0-open-grok.76

This release selectively ports compatible reliability, security, and terminal improvements from upstream Grok Build snapshots `d92c5b0b` and `19d42e35`.

## Security and provider isolation

- Worktree cleanup verifies that a Git registration points back to the worktree being removed, preventing a crafted pointer from deleting a sibling registration.
- Remote campaign and version-override patches cannot install local provider commands, MCP servers, notification hooks, or status-line commands.
- Auxiliary summarization strips provider-native backend tool calls alongside reasoning and tool output so opaque provider history cannot cross routes.

## Terminal and goal behavior

- Plain email addresses in Markdown and terminal scrollback open as safe `mailto:` links, while SCP-style Git remotes remain plain text.
- Email addresses are no longer misread as `@file` prompt references.
- `/goal` keeps objective-named CI, pipeline, remote-job, and deployment verdicts as gating evidence instead of silently replacing them with local checks.

## Video generation

- xAI video generation now recognizes zero-data-retention output-storage failures during start and polling and returns stable setup guidance instead of a generic HTTP error.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding, Code Mode transport behavior, and the fork's restrictive subagent capability controls.
