# Open Grok v1.0.0-open-grok.73

This release assigns published context windows to Wafer AI models.

## Wafer context windows

Wafer `/models` returns ids only, so every catalog entry previously
fell back to 200,000 tokens. Open Grok now matches normalized ids and
sets:

- **1,000,000** for Kimi K3 / K3 Fast, DeepSeek V4 Flash, and GLM 5.2 /
  5.2 Flash
- **262,144** for Kimi K2.6
- **203,000** for GLM 5.1

Unknown Wafer ids stay at the 200,000 fallback. A `[model.*]`
`context_window` override still wins.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
