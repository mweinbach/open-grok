# Open Grok v1.0.0-open-grok.82

Open Grok now starts new sessions inside the workspace sandbox by default and
includes selected improvements from the latest Grok Build 1.0.6 snapshot.

- Protect the host filesystem by restricting agent writes to the active
  workspace, Open Grok state, and temporary directories unless sandboxing is
  explicitly disabled. Existing configuration, managed requirements, and
  resumed-session sandbox profiles continue to take precedence.
- Add browser-style prompt selection and clipboard editing, including shifted
  word and line navigation, Command-C/Command-X, selection replacement, and
  single-step undo.
- Show securely validated MCP server and tool icons through the agent-client
  protocol while rejecting unsafe icon sources and bounding icon metadata.
- Preserve authentic runtime identity and plugin-owned variables in command and
  HTTP hooks, including values interpolated into hook URLs.
- Resolve repository HEAD directly from Git references so large or damaged
  commit packs no longer prevent session startup, status, or file watching.
- Restore web-search, X-search, and Codex permission regression fixtures.
