# Open Grok v1.0.0-open-grok.82

This is a `megascan/open-grok` release from the 1.0.0-open-grok.77 line. It
adds live OpenRouter inference, Codex GPT-5.6 context-window opt-in, and
retargets installers and in-app updates to this repository.

It is not a port of upstream `mweinbach/open-grok` .78–.81.

## OpenRouter

- OpenRouter is a first-class provider with live model discovery and
  advertised reasoning efforts.
- Configure its API key from Settings or `/login openrouter`, or set
  `OPENROUTER_API_KEY`. Attribution headers identify this repository.

## Codex GPT-5.6 context window

- Unset keeps the product-tuned catalog default (~353K effective).
- Opt into the published ~1.05M raw window with Codex-compatible keys:

```toml
model_context_window = 1000000
model_auto_compact_token_limit = 900000
```

- Per-model `[model.*] context_window` still wins. xAI and other providers
  are unchanged.

## Install and updates

Installers, `open-grok update`, and launch auto-update now resolve GitHub
Releases from `megascan/open-grok` instead of `mweinbach/open-grok`.

```powershell
irm https://github.com/megascan/open-grok/releases/latest/download/install.ps1 | iex
open-grok --version
```

```sh
curl -fsSL https://github.com/megascan/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
