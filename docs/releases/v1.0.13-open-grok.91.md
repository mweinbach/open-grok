# Open Grok v1.0.13-open-grok.91

### Sessions and worktrees

- Scroll to the end of `/resume` or press `F5` to load up to 30 more sessions.
  The picker can show titled sessions older than 30 days. If a page fails,
  `F5` retries it and keeps your place. Title searches match word prefixes in
  any order. A unique exact title or session ID can open directly.
- Large session histories now use gzip when it saves space. Resume, search,
  fork and rewind read both formats, and exports produce readable JSONL.
  If you downgrade to `.90`, it cannot open a history once it has been
  compressed.
- Worktree copies preserve tracked edits, deletions and the on-disk spelling
  of filenames, and respect Git exclusions for untracked files. Managed
  worktree removal and resume check the destination's identity. Copying into
  a worktree also protects files outside it from writes through links.

### Models and providers

- Codex compatibility is pinned to `0.167.0-alpha.3`, with eight refreshed
  offline catalog entries. On first sign-in, Open Grok selects the first
  visible model offered by the account. Explicit and saved choices take
  priority. For models that advertise multiple context sizes, select one
  with `/context-window` or the model picker.
- When Codex reports an incomplete response, Open Grok retains tool calls
  the stream already marked complete. Chat
  Completions retries incomplete streams before acting on partial tool calls.
- An optional Antigravity ACP integration lets unrestricted general-purpose
  subagents use models advertised by the signed-in account. It uses a
  separate runtime and profile. [Setup and current limits](https://github.com/mweinbach/open-grok/blob/v1.0.13-open-grok.91/docs/agents/antigravity-acp.md).

### Agent and terminal behavior

- Explicit Plan mode takes effect before the first prompt in new or resumed
  sessions, including headless runs. Headless runs also wait for pending
  background follow-ups and report a timeout if they cannot finish.
- Plugin updates stage a replacement before activation. Skills, commands and
  named agents loaded from a plugin must stay inside its directory. Overlapping
  MCP prompts keep responses in order and approvals tied to the original request.
- In the composer, `Ctrl+S` stashes a draft with its images. Sending the
  next prompt restores the stash. During a running turn, `Esc` leaves the
  draft intact and points to `Ctrl+C` for cancellation. Long conversations
  also scroll more smoothly as new output arrives.
- The optional Memory v2 store carries earlier notes into topics and can
  recover interrupted batch consolidation.
- Linux arm64 self-update now selects the arm64 release binary.

This release includes changes adapted from the public Grok Build 1.0.41 and
1.0.45 snapshots. [Snapshot changes and coverage](https://github.com/mweinbach/open-grok/blob/v1.0.13-open-grok.91/docs/upstream/1.0.45-parity.md).
