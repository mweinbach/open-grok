# Open Grok v1.0.0-open-grok.65

This release adds forked-context subagents with cross-model digest seeding and improves ChatGPT Codex prompt-cache hit rates through per-conversation session affinity.

## Forked-context subagents

- Adds an optional `context` parameter (`"fork"` or `"fresh"`) to the `task` tool so the model can spawn subagents that inherit the parent conversation.
- Adds per-model `subagent_context_default` metadata (catalog JSON, Codex wire catalog, and `[model.*]` overrides); `gpt-5.6-sol` defaults to forked context.
- Same-model forks mirror the parent conversation verbatim, trimming only the incomplete mid-turn tail, and inherit the parent's prompt-cache identity.
- Cross-model forks seed the child with a plaintext `<forked_context>` digest (reasoning summaries and condensed tool traces only) under a token budget, with a one-shot LLM compaction pass when over budget. Raw or encrypted provider payloads never cross a model boundary.

## Prompt caching (ChatGPT Codex)

- Sends `session-id`, `thread-id`, and `x-client-request-id` affinity headers plus a stable `prompt_cache_key` on Codex Responses requests, enabling per-conversation prompt caching across turns.
- Verbatim forked children reuse the parent cache identity via a new cache-affinity id (fallback: session id).

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.
