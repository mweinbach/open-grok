# Open Grok v1.0.0-open-grok.69

This release stops incremental turns from soft-trimming already-sent tool
results, so the prompt-cache prefix stays intact.

## Prompt cache: no mid-session tool-result rewrites

- Incremental requests no longer soft-trim or hard-clear old `exec` / tool
  results once context crosses 50%. Those rewrites broke the cached prefix
  and billed most of the body at the uncached rate.
- Hard-clear of retained history on every user message after 10 turns is
  gone for the same reason.
- Tool-result prune still runs when the next request is already a cold
  prefix: the compact-model input (clone only) or a model swap (in place).
- Image eviction at the 50 MB request-body ceiling is unchanged.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
