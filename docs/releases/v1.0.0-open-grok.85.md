# Open Grok v1.0.0-open-grok.85

Open Grok fixes native Codex subagent requests failing with
`Expected an ID that begins with 'amsg'`.

- Generate the required `amsg_<UUID>` message IDs for native agent spawning,
  messaging, and follow-up tasks.
- Repair legacy bare UUID message IDs from saved history and queued mail when
  preparing Codex requests, so existing sessions can retry without deleting
  their history or editing session files.
- Preserve encrypted content, valid provider IDs, and provider isolation across
  normal Responses, Responses Lite, streaming, and compaction requests.
