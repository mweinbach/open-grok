# Open Grok v1.0.0-open-grok.70

This release imports three compatible upstream reliability improvements and
speeds up the cross-platform release pipeline.

## Streaming and tool activity

- Minimal mode keeps a streaming assistant message open when thinking arrives
  between message chunks, preventing premature commits and split output.
- Tool argument streaming now uses clearer activity labels for file writes,
  edits, commands, workflows, media prompts, questions, and MCP tools.

## Process reliability

- Local shell, terminal, glob, and search processes reuse a cached null-device
  descriptor, so spawning remains reliable if the original `/dev/null` path is
  replaced or temporarily unavailable.

## Release pipeline

- Release builds preserve restored Cargo artifacts instead of deleting the
  most expensive workspace outputs before every build.
- Distribution builds omit unused debug information and use four codegen units
  while retaining thin LTO, reducing the long macOS link bottleneck.
- CI records Cargo timings on macOS failures and uses a fresh cache generation
  plus current GitHub artifact actions.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
