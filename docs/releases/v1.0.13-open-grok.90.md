# Open Grok v1.0.13-open-grok.90

This release replays published Grok Build 1.0.32 client behavior onto Open
Grok. Credentials, paths, and Code Mode stay isolated. The product version
keeps the 1.0.13 line and advances the fork serial; it does not claim
1.0.33/1.0.34 source parity.

- Add Memory v2 as an opt-in store at `$OPENGROK_HOME/memory-v2/`, with
  capture, `/dream`, `/flush`, `/memory status`, and forget. Experience
  memory and `$OPENGROK_HOME/memory/` stay untouched; remote xAI flags
  cannot default it on.
- Ship the feedback draft ACP, taxonomy modal, send-from-draft path, and
  parent-only `send_feedback` tool. Diagnostic upload-trace stays omitted.
- Raise MCP catalog keys to 256 characters, append `structuredContent`,
  and add 2026-07-28 MRTR elicitation (`rmcp` 3.2, `server/discover`).
- Add closed `steer` / `queue` / `interject` delivery, parent wait
  interrupt, continue-after-finish child wake, and a 1-hour wait ceiling.
- Redesign the session header as one overlay row, add workflow dock rows,
  click-collapse, Tab/Ctrl+G dock cycle, dashboard search indication, and
  the dashboard `/resume` opener. Dock v2 stays `GROK_DOCK_V2`.
- Label folded subagent groups as running versus completed, and name
  turn-cancelled banners from trigger and category instead of always
  "by user". Elapsed time rolls over into hours (`3h14m`).
- Run complete builtin slash commands from plan-approval notes without
  deciding the plan; approve refuses a builtin freeform.
- Refresh session-less `x.ai/plugins/list`, `x.ai/skills/*`, and
  `x.ai/commands/list` from disk `.opengrok` config before the first
  session.

See the [1.0.32 parity ledger](../upstream/1.0.32-parity.md) for imported
batches, compatibility decisions, and intentional omissions (login crate
extraction, OTEL upload, Grove-only protocol guesswork, default-on dock,
Windows ARM64 first-handshake TLS).
