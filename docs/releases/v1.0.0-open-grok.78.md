# Open Grok v1.0.0-open-grok.78

This release fixes reasoning-token rendering for OpenRouter models and stops
out-of-menu reasoning efforts from reaching models that reject them.

## Reasoning rendering on OpenRouter

- Chat Completions streaming now understands OpenRouter's `delta.reasoning`
  field and structured `delta.reasoning_details` entries, in addition to the
  DeepSeek-style `reasoning_content` alias. Thought chunks from OpenRouter
  models (for example `stealth/ox-alpha`) now render instead of being silently
  dropped.
- When a provider's usage chunk omits
  `completion_tokens_details.reasoning_tokens`, the streamed reasoning text
  backs into an estimate so token accounting stays non-zero.

## Reasoning-effort validation

- A carried-over effort (the global default or a previous model's selection) is
  now checked against the target model's `reasoning_efforts` menu before it is
  applied to a new session. If the model does not offer that value, the
  model's own default is used instead and the substitution is logged.
- This prevents values like `xhigh` from being sent to models whose menus only
  contain low/medium/high/max (for example `zai:glm-5.3`), which previously
  could disable or degrade thinking mode.
