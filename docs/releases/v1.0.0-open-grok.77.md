# Open Grok v1.0.0-open-grok.77

This release adds OpenRouter as an opt-in provider with the same explicit
model-enablement flow as OpenCode Go.

## OpenRouter

- Configure its API key from Settings or `/login openrouter`, or set
  `OPENROUTER_API_KEY`. Open Grok queries the live model API and displays a
  checklist of discovered text and tool-capable models.
- No OpenRouter models are enabled by default. Only selected models appear in
  normal model settings and are eligible for subagents.
- Stored keys are sent only to `https://openrouter.ai`. Image, embedding, and
  non-tool models are omitted from the checklist.
- Models that advertise reasoning expose none/low/medium/high/xhigh (Medium
  default). Requests include OpenRouter attribution headers.
- Credential and enabled-model changes refresh the catalog and rebind loaded
  OpenRouter sessions without a restart.
