# Open Grok v1.0.0-open-grok.75

This release makes prompt-cache telemetry distinguish provider reporting from actual cache-hit quality and adds clearer diagnostics for lower hit rates.

## Cache hit-rate reporting

- `/cache` now shows both the all-provider steady-state hit rate and a supported hit rate limited to requests where the provider reported cached tokens.
- Requests that report no cached tokens with an intact prompt prefix are counted separately and displayed as `no cache reported` instead of misleading `0.0% hit` rows.
- Sessions using only non-reporting routes show the supported rate as unavailable rather than silently omitting it.

## Provider diagnostics

- Cache turn telemetry records the canonical provider, model ID, and inter-request gap.
- Partial hits with intact prefixes distinguish long gaps that likely allowed provider cache expiry from short-gap cases that may be caused by newly appended content, provider routing, or eviction.
- `x.ai/session/cache` exposes the new summary and turn fields additively, preserving compatibility with older stored records.
- Model selection behavior is unchanged; routes that do not report prompt caching remain available.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.
