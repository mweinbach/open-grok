# Open Grok v1.0.0-open-grok.62

This release completes a comprehensive upstream sync (Batches B1–B9), modularizes key workspace subsystems into dedicated crates, and hardens session event tracking, Code Mode state invalidation, and UI selection handling.

## Upstream sync & workspace modularization

- **Extracted workspace crates.** Modularized core session concerns into independent crates: `xai-grok-session-events`, `xai-grok-session-search`, `xai-grok-foreign-sessions`, `xai-grok-active-sessions`, `xai-grok-bundle`, and `xai-compaction-transcript`.
- **Code Mode rewind invalidation.** Rewinds now explicitly reset the persistent JavaScript runtime generation and invalidate stale timeline state.
- **TUI & Selection UX.** Pager selection wrapping, UX packs, ACP tracker synchronization, and foreign session lifecycle management.
- **Owner-only permissions & sandbox hardening.** Enforce strict permissions on session storage and search indexes, with normalized sandbox paths.

## Multi-provider compatibility

- Full isolation across xAI, Codex, Kimi Platform, Kimi Code, Fireworks AI, DeepSeek direct, Wafer AI, and Z AI.
- Preserved export boundaries, credential containment, and zero-cross-contamination guarantees.
