# Open Grok v1.0.13-open-grok.88

This release adds GPT-6 Astra catalog support, optional context-management
tools, and reliable async user messaging on OpenAI Responses API routes.

- Adopt Codex 0.153.1 model metadata, including Astra naming, raw context
  overrides, migration notices, and advertised reasoning controls. Max remains
  Max; Ultra follows the model's advertised multi-agent effort.
- Add opt-in persistent work and browser action review settings, with
  per-call confirmation policies for compatible MCP tools.
- Add experimental model-controlled context windows with durable local
  history and notes, checkpoint acknowledgment, and preservation of concurrent
  user steering. The feature is off by default and requires a restart.
- Honor `send_user_message_async` capability opt-ins through TOML and the
  custom-model API. Explicit empty lists disable the tool, and API aliases
  retain their own transport and tool settings during request reconstruction.
  API-key routes can use ordinary Responses without Codex Lite.

Validation: 16 focused sampler and shell tests passed, including a mock
Responses request/acknowledgment round trip, metadata persistence, catalog
capability gates, and alias handling. All five experimental context-management
runtime tests also passed on Windows, covering durable checkpoint boundaries,
concurrent steering, context budgets, and provider-switch revocation.
Both confirmation-policy and fail-closed review tests passed as well.
