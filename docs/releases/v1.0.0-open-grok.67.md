# Open Grok v1.0.0-open-grok.67

This release adds isolated RunInfra and Google Gemini (AI Studio) providers, and keeps Codex 401s from inheriting xAI login-recovery copy.

## RunInfra

- Adds an API-key-only Chat Completions provider at `https://api.runinfra.ai/v1` (`RUNINFRA_GATEWAY_KEY` / `RUNINFRA_API_KEY`, `/login runinfra`).
- Discovers models from live `/v1/models` with a curated hosted fallback. Known hosted models expose a reasoning-effort menu; `deepseek-v4-flash` defaults to max.
- Stored keys stay on `https://api.runinfra.ai`. No Responses dialect, hosted tools, native search, or xAI export path.

## Google Gemini (AI Studio)

- Adds an API-key-only Chat Completions provider at `https://generativelanguage.googleapis.com/v1beta/openai/` (`GEMINI_API_KEY` / `GOOGLE_API_KEY`, `/login gemini`).
- Shows four curated models (`gemini-3.7-flash`, `gemini-3.6-flash`, `gemini-3.5-flash-lite`, `gemini-3.1-pro-preview`). Live `/models` may enrich those entries only.
- Gemini 3 cannot use reasoning effort `none`. 3.7 Flash and 3.1 Pro reject `minimal` (low/medium/high); 3.6 Flash and 3.5 Flash-Lite offer minimal/low/medium/high. Defaults: Medium, Medium, Minimal, and High.
- Stored keys stay on `https://generativelanguage.googleapis.com`. No Responses dialect, hosted tools, native search, or xAI export path.

## Auth isolation

- Codex 401s no longer inherit xAI `SelfHealing` / `auth_transient` remedies, so the pager keeps the Codex re-auth banner instead of hiding it.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
