# Open Grok v1.0.13-open-grok.87

Open Grok v1.0.13-open-grok.87 adds native Google AI Studio inference support,
the Factory Droid mission engine and orchestration tools, first-class OpenRouter
reasoning integration, and sandbox confinement improvements.

- Add Google AI Studio native inference backend (`api_backend = "google_ai_studio"`),
  including `streamGenerateContent` SSE transforms, thinking tokens, function calling,
  `x-goog-api-key` authentication, model discovery, and compaction support.
- Implement Factory Droid mission engine, file storage, and discovery with new
  orchestrator and worker tools (`propose_mission`, `start_mission_run`,
  `dismiss_handoff_items`, `inspect_mission_readiness`, `end_feature_run`),
  plus the `/mission` slash command.
- Add OpenRouter provider support with opt-in catalog discovery, provider-local
  reasoning efforts, and nested thinking token mapping.
- Restore opt-in workspace sandbox confinement and reinforce provider isolation boundaries.
- Release workflow hardening: require explicit workflow dispatch and verified latest
  publication across macOS arm64, Linux x86_64/arm64, and Windows x86_64.

Validation: passing unit and integration suites across `xai-grok-sampling-types`,
`xai-grok-sampler`, `xai-grok-shell`, `xai-grok-tools`, `xai-grok-pager`, and
`xai-grok-pager-bin`, including local Mach-O release build, isolated installer smoke,
and version check.
