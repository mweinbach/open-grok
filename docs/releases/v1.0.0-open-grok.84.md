# Open Grok v1.0.0-open-grok.84

Open Grok adds model-metadata opt-ins for Codex transport, messaging, and native
collaboration tools while preserving existing behavior on other routes.

- Enable Responses Lite only when a Codex Responses model advertises
  `use_responses_lite`, including streaming and compaction requests.
- Expose `send_user_message_async` only when listed in
  `experimental_supported_tools`. Root agents can send a visible, persisted
  message without ending their turn or waiting for a reply.
- Use native grammar-backed `apply_patch` when `apply_patch_tool_type` is
  `freeform`, retaining normal plan-mode gates, hooks, permissions, and write
  attribution. Code Mode Only keeps patch editing nested under `tools.*`.
- Adapt `multi_agent_version = "v2"` to named, reusable agents with durable
  identity, selective history forks, follow-up wake/resume, activity waits,
  and turn interruption. Existing flat-team and spawn-depth limits still apply.
- Preserve provider-owned encrypted agent messages and native tool metadata
  through streaming, replay, and Lite requests without forwarding private
  content into other providers or plaintext compaction artifacts.
- Keep these capabilities off when metadata is missing or unsupported, retain
  legacy collaboration semantics elsewhere, and preserve ordinary cross-provider
  task delegation.
