# Open Grok v1.0.0-open-grok.81

Code Mode now streams the actual nested file, terminal, search, and other tool
activity without exposing internal `exec` or `wait` wrappers, JavaScript source,
or transport arguments in the terminal UI, dashboard, or restored sessions.

- Show sanitized previews for concurrent and incrementally generated nested
  tool calls, then replace them with their authoritative tool cards.
- Stream nested-tool progress both to visible tool cards and JavaScript
  `onProgress` observers, with bounded buffering, reliable ordering,
  cancellation, and isolated concurrent callbacks.
- Preserve legitimate ordinary tools named `exec` or `wait` while filtering
  Code Mode transport artifacts from live and replayed sessions.
- Correct interleaved and incomplete provider tool-call streams across the
  Responses, Chat Completions, and Messages APIs.
