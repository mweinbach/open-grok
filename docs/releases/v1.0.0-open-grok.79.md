# Open Grok v1.0.0-open-grok.79

This release adds search and mouse scrolling to the model catalog sub-sheets
in Settings — most visibly the OpenRouter model picker, whose live catalog
can be hundreds of models long.

## Model catalog search

- The OpenRouter, OpenCode Go, and custom-model sub-sheets now have a
  `search:` bar under the header. Press `/` to focus it and type to filter
  the list case-insensitively against both the display name and the model
  id (typing `gpt` finds `openai/gpt-4o`). Pasting a query works too.
- A match counter (`12/340`) appears at the right of the bar while
  filtering; an empty result renders "No matches for …".
- Enter commits the query so Space/Enter toggle the highlighted model;
  Esc clears a non-empty query first and exits the sheet on a second
  press. Clicking the search bar also focuses it.
- Static toggle groups (for example contextual hints) keep their exact
  prior behavior; the footer only advertises `/ search` on dynamic
  catalogs.

## Mouse scrolling in sub-sheets

- The scroll wheel previously did nothing in these sheets. It now pans
  the viewport (~3 rows per tick) with an offset clamped to the list,
  while keyboard navigation still keeps the focused row visible.
- Clicks map through any active filter, so clicking a filtered row
  toggles the correct underlying model.
