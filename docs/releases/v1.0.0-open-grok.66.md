# Open Grok v1.0.0-open-grok.66

This release stops request-time tool-result pruning from flapping the prompt-cache prefix on long sessions.

## Prompt cache stability

- Gates request-time prune on the unpruned in-memory conversation size (and the last API total), not the last pruned `prompt_tokens` report. Soft-trim only rewrites the outgoing clone, so using that smaller usage figure was turning prune off again and alternating full vs trimmed prefixes every other loop.
- Raises request-time keep/hard-clear thresholds by the same synthetic `User` count retained hard-clear already uses, so interjections and similar injections do not age tool results a turn early.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
