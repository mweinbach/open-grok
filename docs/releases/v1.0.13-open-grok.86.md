# Open Grok v1.0.13-open-grok.86

Open Grok integrates the published Grok Build 1.0.13 client changes while
preserving multi-provider support, native Codex, Code Mode, and isolated state.

- Improve inference retries, length continuation, truncated tool-call recovery,
  image normalization, and compaction error reporting.
- Persist durable turn completions, cancellation details, elapsed time, and
  headless-session history; preserve exact task identity during finalization.
- Expand hook decisions and post-tool context, MCP elicitation and authentication,
  persistent permission choices, and signed managed-policy refresh.
- Improve subagent startup, follow-up delivery, scoped waits, workflows, and
  scheduler lifecycle handling without weakening model-authored input boundaries.
- Add prompt stash/restore, minimal/fullscreen switching, fullscreen external
  editing, improved status lines and rendering, image-only feedback, and billing retry.
- Add Git-backed `clone` with shallow history by default and `--full-history`
  support; Grove remains an explicit opt-in. Improve worktree and watcher behavior.
- Support checksum-verified compressed release downloads while retaining raw
  release-asset compatibility.
- Include the custom-endpoint provider and model discovery added since the
  previous release, with explicit credentials and provider-local routing.

Validation: 27,387 passing unit tests, 110 selected integration tests, final
application/test-target compilation, and local version/help/completions/clone
smoke checks. Existing ignored tests and host-blocked PTY, HEIC, and process
checks are not counted as passing. Live Grove/NFS and Windows/Linux runtime
behavior were not exercised on the macOS validation host.

See the [upstream parity ledger](../upstream/1.0.13-parity.md) for the exact
baseline, compatibility decisions, test evidence, and unpublished-service limits.
