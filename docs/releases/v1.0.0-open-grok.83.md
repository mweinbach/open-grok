# Open Grok v1.0.0-open-grok.83

Open Grok now learns from verified coding experience instead of treating prior
sessions as passive context. Ordinary coding sessions and goal-driven workflows
can both reuse practical recommendations, known failure modes, and repository
constraints without retrieving entire historical conversations.

- Capture evidence-backed successful patterns, anti-patterns, environmental
  facts, process improvements, architectural lessons, and uncertain hypotheses
  from real tests, compilation, runtime results, and explicit user feedback.
- Rank prior experience by task, repository, environment, outcome quality,
  confidence, age, and demonstrated reuse; surface compact Recommended, Avoid,
  and Uncertain guidance before planning and after verified execution failures.
- Search verified successes and failures directly with `experience_search`,
  including supporting commands, redacted evidence, and exact `experience:`,
  `run:`, and `session:` references back to the original work.
- Reinforce only recommendations that were actually followed, consolidate
  repeated lessons, preserve contradictory evidence and exceptions, and bound
  storage growth with conservative repository-specific generalization.
- Protect credentials and prompt boundaries with persisted-secret redaction,
  hostile-markup sanitization, verified tool provenance, host-isolated repository
  identity, and backward-compatible migration from existing memory databases.
- Add deterministic evaluation and ablation coverage for repeated-failure
  avoidance, recommendation utility, regressions, retries, quality, execution
  time, and memory-context token usage.
- Preserve the existing memory controls, first-turn prompt cache, ephemeral
  session behavior, and regular non-goal workflows.
- Improve release build caching and linking, and show the manual Codex sign-in
  URL when the browser cannot be opened automatically.
