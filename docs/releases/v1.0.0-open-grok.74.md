# Open Grok v1.0.0-open-grok.74

This release adds a prebuilt Linux x86_64 client.

## Linux x86_64

- The GitHub release now publishes `open-grok-linux-x86_64` and its
  SHA-256 file alongside the macOS and Windows assets.
- `install.sh` detects Linux x86_64 and installs that artifact. The same
  curl installer still installs Apple Silicon macOS.
- In-app `open-grok update` selects the Linux x86_64 asset on that
  platform.

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.
