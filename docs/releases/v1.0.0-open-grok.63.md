# Open Grok v1.0.0-open-grok.63

This release introduces prompt cache hit rate tracking, prefix divergence break diagnostics, the `/cache` slash command, interactive Settings UI for custom model management, and intelligent Z AI context window handling.

## Prompt cache hit rate & break diagnostics

- **Prompt cache hit rate in `/usage` & `/cache`.** View prompt cache hit rate percentages (`cached_prompt_tokens / prompt_tokens * 100%`) in `/usage` input token rows and multi-model breakdowns, or use `/cache` (`/cache-status`, `/prompt-cache`) for detailed session cache summaries and recent turn history.
- **Granular prefix divergence tracking.** Automatically logs when and why prompt caching breaks across consecutive turns, detecting system prompt diff offsets, tool modifications or reordering, pruned tool results (`[Tool result omitted — too old]`), image evictions, and item edits in `unified_log` and `tracing`.
- **Session cache RPC endpoint.** Added `x.ai/session/cache` ACP endpoint returning cumulative cache statistics and turn-by-turn telemetry records.

## Custom models & provider enhancements

- **Interactive custom models TUI.** Settings → Models → Custom models lets you add, configure, and remove custom model entries (`[model.*]` in `config.toml`) directly from the pager UI.
- **Catalog refresh persistence.** Custom models and context window overrides survive live `/models` catalog updates from dynamic providers like Z AI and Wafer AI.
- **Z AI context window assignment.** Accurate context window sizing for Z AI models (1M for GLM-5.2, 200k standard, 128k for 32b/128k ids) with telemetry logging.

## Multi-provider compatibility

- Full isolation across xAI, OpenAI Codex, Kimi Platform, Kimi Code, Fireworks AI, DeepSeek direct, Wafer AI, and Z AI.
- Preserved export boundaries, credential containment, and zero-cross-contamination guarantees.
