# Open Grok v1.0.0-open-grok.72

This release restores the Windows build and ships the same session-bus,
working-directory, and streamed-tool-call work from v1.0.0-open-grok.71
to both platforms.

## Windows

- Leader IPC types are public inside the private Windows transport module
  so `LeaderListener` / `LeaderStream` can be re-exported to the server
  and client. v1.0.0-open-grok.71 was macOS-only because this visibility
  error failed the Windows job.

## Session bus

- Live sessions on the same machine can discover each other and exchange
  messages through `$OPENGROK_HOME/session-bus/` presence files and
  per-process IPC. Root sessions get `list_sessions`, `read_session`, and
  `message_session`. Delivery reuses the idle-wake mailbox; peer bodies
  stay untrusted model input.
- The TUI renders incoming peer session messages as their own cards.
- `[session_bus] enabled = false` opts a process out.

## Working directories

- `/add-dir` and `/remove-dir` attach extra directories to the live
  session so tools can work outside the original project root.
- Permission rules can be appended or reset at runtime when those
  directories are added.

## Streamed tool calls

- Grok Responses now requests incremental tool-call argument deltas by
  default. Codex, DeepSeek, Meta, Chat Completions, and Messages already
  stream fragments and never receive the xAI-only request field.
- Settings → Advanced → Stream tool calls (`[ui].stream_tool_calls`,
  default on) turns the request and the TUI “Writing file/edit/command…”
  activity on or off. A per-model `stream_tool_calls = false` remains the
  BYOK escape hatch.

## Reliability

- Resume keeps the prompt-cache identity so a restored session still
  hits the same prefix cache.
- Environment updates append instead of rewriting the instruction
  prefix.
- Completed and aliased task kills resolve to the right child run.
- Z AI GLM-5.x models are treated as text-only; `glm-5.3` uses a 1M
  context window.

## Compatibility guarantees

- Keeps Open Grok state isolated under `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/` paths.
- Preserves independent credentials, catalogs, hosted tools, and export boundaries for every supported provider.
- Retains Open Grok branding and Code Mode transport behavior throughout.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
