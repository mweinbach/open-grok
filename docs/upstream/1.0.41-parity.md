# Grok Build 1.0.41 parity ledger

## Scope

The published GitHub snapshot is `07e35a3dfeed2f200d319ef6c893b5ea286d9a51`
(2026-09-22, crate version **1.0.41**). The previous Open Grok import target
was `482711333c7195dc16a272777f86086d615e2afb` (2026-09-15, **1.0.32**).
`git merge-base HEAD upstream/main` is empty: histories have no merge base,
so this is a snapshot replay, not a merge or rebase.

This replay covers upstream **1.0.33–1.0.41**, including the 1.0.33/1.0.34
items deferred by the 1.0.32 ledger for lack of published source. The public
changelog page lags the GitHub snapshot (1.0.34 at inventory time), so the
snapshot is the newest source available.

Fork contracts stay: `$OPENGROK_HOME` / `~/.opengrok`, multi-provider
isolation, Code Mode, session bus, experience memory, plan-mode edit gate,
and Open Grok branding. Fork crate versions stay `1.0.0`; upstream
`1.0.32` → `1.0.41` version bumps are not ported.

## Compatibility decisions

- `xai-grok-login`, `xai-grok-otel`, `xai-grok-image`, `xai-grok-gboom`, and
  `xai-grok-shell-terminal` stay omitted, as in the 1.0.32 replay. New
  upstream `xai_grok_login` call sites are mapped onto fork auth; shell
  `test-support` forwards sampler + workspace seams only.
- Upstream `SOURCE_REV` and shell `CHANGELOG.md` stay untracked; the
  per-version `changelogs/1.0.{33..41}.{md,json}` files are the imported
  record. `THIRD-PARTY-NOTICES` takes the onig/Oniguruma hunk only.
- `sports_search` (1.0.41 notes) has no client source in the snapshot;
  it is a server-side tool and needs no port.
- `AccessKind::Tool` refcount is unchanged (38 → 38); the fork deferral
  stands. Dock v2 stays env-gated; `upload-trace` and
  `xai-message-delivery-core` stay omitted.
- Memory v2 carryover is ported into the isolated
  `$OPENGROK_HOME/memory-v2/` tree; legacy `$OPENGROK_HOME/memory/`
  stays the carryover *source* only and is never written by v2.
- `SandboxMode::Bare` is removed with upstream; the fork-only
  `SandboxMode::Agent` stays.
- `syntect`/`two-face` move to `default-onig` with upstream (1.0.35
  highlighting perf); `tree-sitter` moves to the `0.26` workspace pin.
  `rmcp` stays `3.2.0`, matching the fork pin.
- Upstream's MCP-init rework (`InitClaimGuard`, `run_startup`,
  `start_mcp_init`, `SnapshotRefresher`) is not adopted; the fork keeps
  its `ensure_mcp_tools_initialized` + `refresh_mcp_snapshot_*` flow.
  `is_init_abandoned` is approximated (pre-finish pass with a settled
  failure reads as abandoned) to satisfy the connecting-reminder
  contract without the claim machinery.
- Upstream's session plugin prefetch (`session_create_prefetch.rs`,
  `join_plugin_registry`) is not ported; plugins resolve via the
  agent-level lazy registry. The spawn timer test drops the
  `plugin_refresh` probe; the other five subphase timers are ported.
- Upstream's dashboard row rework (`WorkspaceView`,
  `WorkspaceRowInputs`, cluster/group sorting, provisionals) is not
  adopted; the fork builder gains minimal member ordering (pinned
  first by manual rank then session id, unpinned keep snapshot
  order) plus the `pinned` flag. Dashboard render now goes through
  `layout_with_preview` so preview-off stays off.
- The direct-call MCP coercion path keeps the fork init flow: the
  coercion test's stub registers the full schema because prepare's
  init refresh rebuilds snapshot rows from live definitions.
- Prompt templates take upstream 1.0.41 wording, including the
  removed subagent "Prefer specialized tools" line; the fork-only
  rendered-prompt test now asserts the remaining tool_calling section.
- `RUST_MIN_STACK=8388608` in `.cargo/config.toml` `[env]`: debug
  `SessionActor` futures exceed the default 2 MiB test-thread stack
  (stack overflow abort in `mcp_file_input` tests); 8 MiB matches the
  codebase's known-good floor.

  (`flush_config`, `dream_config`, `save_on_end`, injection, idle
  timeouts), launch dream (`spawn_dream_check` + timer guard +
  teardown `stop_dream`), exit dream removed from the end pipeline.

  (`hand_off_foreground_subagents` answers into
  `repair_dangling_after_harness_halt`); previously empty answers.

  tail in `handle_session_notification`).
- Session-create subphase timers (`session_env`, `git_discovery`,
  `tool_overrides_echo`; `plugin_refresh` dropped, see decisions).
- Prompt widget: selection counts as `Edited`; image resync only on
  text change; `restore_elements` skips invalid ranges.
- Memory modal: notice hides list hotkeys; status line renders in the
  file list.
- Dashboard preview render via `layout_with_preview`; member pin/order.
- MCPS modal: `setup_required` derives from status (policy verdict wins).
- Question view reverse-video overlays + theme `selection_overlay` /
  `hover_overlay` / `is_bandless` API.
- Minimal `/home` opens a fresh session; minimal `/new` drops other
  agents (`drop_other_agents_in_minimal`).
- Miscellaneous ported test updates taken verbatim: video-gen
